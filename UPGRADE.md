# Апгрейд и перенос (с сохранением данных)

Как перейти на более мощную видеокарту (16/24/32 ГБ) или новую машину, **не
потеряв** чаты, аккаунты, настройки и скачанные модели.

## Где живут данные

Всё хранится в именованных Docker-томах (НЕ в папке репозитория):

| Том | Что внутри | Заменимо? |
|---|---|---|
| `local-ai_open_webui_data` | чаты, аккаунты, настройки, RAG-документы | ❌ **незаменимо** — это «база» |
| `local-ai_ollama_models` | скачанные модели | ⚠️ можно перекачать, но долго |

Важно про команды:
- `docker compose down` — **данные сохраняются** (тома остаются).
- `docker compose down -v` — **тома удаляются**, всё теряется! Не делай без бэкапа.
- Имя проекта закреплено (`name: local-ai` в compose) → имена томов стабильны и
  не зависят от имени папки.

## Сценарий A. Апгрейд видеокарты на той же машине

Самый простой случай — данные не трогаются вообще.

```powershell
docker compose down          # 1. выключить стек (тома сохранятся)
# 2. заменить видеокарту физически
# 3. поставить свежий драйвер NVIDIA
docker compose up -d         # 4. поднять обратно
```

Конфиг менять **не нужно**: в compose стоит `count: all`, Docker сам возьмёт
любую установленную видеокарту. С бóльшим объёмом VRAM можно сразу качать
модели крупнее (см. ниже).

## Сценарий B. Перенос на новую машину

```powershell
# НА СТАРОЙ машине:
.\backup-volumes.ps1         # создаст backup\*.tar.gz

# скопировать весь репозиторий ВМЕСТЕ с папкой backup\ на новую машину

# НА НОВОЙ машине (Docker Desktop + драйвер NVIDIA уже стоят — см. README):
.\restore-volumes.ps1        # восстановить данные из backup\
docker compose up -d         # поднять стек
```

Если бэкап моделей не делал — пропусти их при восстановлении и просто скачай
заново: `.\pull-models.ps1`.

## Какие модели поднимать после апгрейда

Главный ограничитель — объём VRAM. С ростом видеопамяти:

| VRAM | Что тянет | Команда (пример) |
|---|---|---|
| 8 ГБ (сейчас) | 7–8B Q4 | `qwen2.5-coder:7b` |
| 16 ГБ | 14B свободно | `ollama pull qwen2.5-coder:14b` |
| 24 ГБ | 32B свободно | `ollama pull qwen2.5-coder:32b` |
| 32 ГБ | 32B + длинный контекст | `qwen2.5-coder:32b` |

После смены модели проверь, что она влезла в видеопамять:
`docker exec -it ollama ollama ps` → колонка `PROCESSOR` должна быть `100% GPU`.
Если там CPU — модель не поместилась в VRAM, бери квант/размер поменьше.

## Регулярный бэкап (рекомендуется)

Чтобы не потерять чаты при сбое — периодически:

```powershell
.\backup-volumes.ps1
```

Папку `backup\` храни вне машины (облако / внешний диск). В git она не
коммитится (см. `.gitignore`).
